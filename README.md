# SharePoint AI Skills

A curated library of reusable AI skills for Microsoft 365 SharePoint.

## Available Skills

| Skill | Description |
|-------|-------------|
| [daily-voice](./daily-voice/SKILL.md) | Assigns a unique speaking style to every day of the year. The agent checks the current date and applies that day's speaking style when appropriate. |
| [m365-roadmap-list](./m365-roadmap-list/SKILL.md) | Retrieves Microsoft 365 Roadmap items for the current month and saves each item as a row in a SharePoint list. |
| [m365-roadmap-monthly-report](./m365-roadmap-monthly-report/SKILL.md) | Generates and saves a polished monthly Microsoft 365 Roadmap report covering items with activity during the current month. |
